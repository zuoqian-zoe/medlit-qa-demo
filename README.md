# MedLit-QA 医疗文献问答 Demo

基于 RAG（检索增强生成）的医疗文献问答最小原型：**上传医疗文献 → 自动切片向量化入库 → 提问时检索相关段落 → 大模型基于检索内容作答并标注来源**。

> 个人学习项目 | 作者：左倩 | 2026-11

## 为什么做这个项目
- 验证 Cloud & AI 解决方案的核心场景之一：**垂直行业知识库问答**（医疗+大模型）
- 亲手跑通 RAG 完整链路：文档解析 → 文本切片 → Embedding 向量化 → 相似度检索 → 大模型生成 → 引用溯源
- 技术栈与企业级方案同构，便于后续迁移到 Azure OpenAI / 企业私有知识库场景

## 架构
```
医疗文献(txt/pdf)
    │  读取 & 切片(400字/块, 60字重叠)
    ▼
Embedding 模型 ──► 向量库(numpy本地存储)
    │
提问 ──► 余弦相似度检索 Top-3 相关段落
    │
大模型(LLM)基于检索内容生成回答 + [1][2]引用标注
```

## 快速开始
```bash
pip install -r requirements.txt
cp .env.example .env   # 填入你的 API_KEY
python app.py
```
浏览器打开 http://127.0.0.1:7860

## 使用步骤
1. 准备2-3篇医疗文献（txt/md/pdf均可，例如指南摘要、药品说明书、综述节选）
2. 点击"构建知识库"等待入库完成
3. 在问题框提问，查看回答与参考来源

## 技术说明 & 已知简化
- 默认使用 OpenAI 兼容接口（硅基流动平台：embedding 免费、LLM 按量计费约0.001元/千token）
- 切换 Azure OpenAI：修改 `.env` 中 `BASE_URL`/`EMBED_MODEL`/`LLM_MODEL` 即可，代码无需改动
- 简化点：固定长度切片（生产用语义切片）、numpy向量库（生产用FAISS/向量数据库）、单用户本地存储
- 这些简化点正是面试时可以主动展开讲"生产环境怎么改进"的素材
